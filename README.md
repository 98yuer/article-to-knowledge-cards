# make-knowledge-cards

一个 WorkBuddy / Claude 技能（Skill）。给它一篇文章或一个 Markdown/TXT 文件，它吐出一组互不重复、能独立读懂的知识卡片——通常 5~8 张，素材撑不起 5 张时会更少。

## 1. 项目解决什么问题

读完一篇长文，脑子里留下的是印象而不是知识点：抓不住重点、记不清依据、复习时还得回去翻原文。普通摘要工具只做"压缩"——把 3000 字压成 300 字，观点仍然混在一起，也无法判断哪些句子是作者的结论、哪些是背景铺垫。

这个技能要解决的是**从文本到可复习知识**这一步，因此它给自己定了三条硬约束：

- **一卡一知识点**：一张卡片里出现两个并列结论必须拆开，宁可少出几张
- **不允许编造**：卡片里不许出现原文之外的事实、数字、因果；原文没写清楚的地方就标注"原文未给出"
- **凑数不如不凑**：5~8 张是上限参考而非指标，素材撑不起 5 张时照实输出并说明原因，不注水

核心优先级 **准确 > 有用 > 数量**。

## 2. 主要功能

| 功能 | 说明 |
| --- | --- |
| 双通道输入 | 支持对话中粘贴的正文，或本地 `.md` / `.txt` 文件路径 |
| 知识点筛选 | 按六类抽取候选：概念定义、因果机制、成立边界、反直觉结论、可复用方法、原文自带的例子与数据；套话与背景铺垫不入候选 |
| 去重合并 | 多段重复叙述合并成一张卡；核心知识高度重叠的两张必须处理掉一张 |
| 结构化卡片 | 每张卡固定四字段：核心知识、简明解释、例子/自测、来源 |
| 份数自适应 | 候选超过 8 张只留价值最高的 8 张；不足 5 张时照实输出并说明 |
| 素材类型适配 | 概念说明型、教程操作型、清单罗列型、学术文献型分别有抓取重点 |
| 学术文献特化 | 公式/表格在粘贴中丢失时不还原；显著性照搬原文，"不显著"不会被写成"成立" |
| 反编造自检 | 出卡前逐条核对 7 项清单，包括"每张卡片的每个事实都能在原文中定位" |

**明确不做**：网页抓取、PDF / DOCX / CAJ 等二进制文档、Anki 导出（`.apkg` 或制表符分隔文件）、图片与 HTML 可视化。遇到这些会直接说明不支持并给出转换路径，不做变通实现。

## 3. 安装方法

技能本体只有两个文件，无脚本、无外部依赖。三种放置方式任选：

```bash
# 全局可用（推荐）
cp -r skills/make-knowledge-cards ~/.workbuddy/skills/

# 项目内共享给协作者
cp -r skills/make-knowledge-cards .workbuddy/skills/

# 不动它也行：本仓库的 skills/ 目录本身就是一份可直接复制的技能包
```

目录结构：

```
make-knowledge-cards/
├── SKILL.md            # 技能主体：6 步工作流、卡片模板、去重与反编造规则
└── agents/openai.yaml  # 展示名、简短描述与默认调用提示
```

校验是否合法（需要 Skill Creator 的 `quick_validate.py`）：

```bash
python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
# → Skill is valid!
```

## 4. 使用方法

不需要命令，直接在对话里提需求即可（技能会按 `SKILL.md` 中的 frontmatter 描述被触发）：

```
把这篇文章做成知识卡片：
<粘贴正文>

把 samples/sample-3-tutorial-with-code.md 提炼成知识卡片
```

等价说法："提炼知识点""整理成复习卡片""把这段变成能背的版本""提取核心考点"。

**输入要求**：粘贴的文章正文，或本地 `.md` / `.txt` 文件路径。其他格式（PDF、DOCX、CAJ 等）会被提示先用原阅读器另存为 TXT 再上传。

**输出**：

1. 一个 Markdown 文件，默认名为 `<原文文件名>-知识卡片.md`（粘贴文本时为 `<主题短语>-知识卡片.md`），放在工作区根目录或用户指定的路径
2. 对话里回三件事：卡片数量、卡片标题列表、未覆盖内容的提醒（哪些段落因重复或信息不足没做成卡）

卡片固定格式：

```markdown
### 卡片 N：<不超过 20 字的知识点名称>

- **核心知识**：一句话结论，最多 2 句，脱离原文也能读懂
- **简明解释**：2~4 句，讲清为什么成立、什么时候成立
- **例子/自测**：原文的例子或数据，或一问一答（答案须有原文依据；技术素材可嵌入 3~8 行代码块）
- **来源**：可回溯的原文位置，便于核证
```

## 5. 输入输出示例

### 示例一：Markdown 文件 → 7 张卡片

**输入**：`samples/sample-1-concept-article.md`（一篇讲系统性风险与 CAPM 的说明文，约 1100 字）。节选其中一段：

> 需要注意的是，β 只描述"跟随市场波动的幅度"，它不描述波动的方向偏好，也不衡量公司的好坏。一家高 β 的公司既可能是一家激进的科技初创公司，也可能是一家债台高筑的传统企业。用 β 判断投资价值是对这个指标的典型误用。

**输出**：`samples/sample-1-concept-article-知识卡片.md`，7 张卡片。其中一张：

```markdown
### 卡片 4：贝塔不能用来评判公司好坏

- **核心知识**：β 只描述跟随市场波动的幅度，不代表公司质地优劣，用它判断投资价值是典型误用。
- **简明解释**：β 不描述方向偏好，也不含基本面信息。原文指出高 β 既可能是激进的科技初创公司，也可能是债台高筑的传统企业——两种截然不同的基本面可以有同样的 β。
- **例子/自测**：问：两家 β 都是 1.5 的公司，能据此判断谁更值得投吗？答：不能，β 不衡量公司好坏。
- **来源**：第二节后段
```

完整 7 张：系统性风险与非系统性风险的分界 / 分散化能消除的是哪一部分 / 贝塔衡量的是敏感幅度 / 贝塔不能用来评判公司好坏 / CAPM 的核心定价判断 / CAPM 的假设与解释力边界 / 阿尔法是扣掉贝塔后的残差。

### 示例二：技术教程 → 8 张卡片，代码进例子字段

**输入**：`samples/sample-3-tutorial-with-code.md`（讲 Python 生成器处理大文件，含多段代码）。

**输出**：`samples/sample-3-tutorial-with-code-知识卡片.md`，8 张卡片。其中一张：

```markdown
### 卡片 4：套一层 list() 就让省内存失效

- **核心知识**：对生成器调用 `list()` 会触发一次性求值，惰性全部作废。
- **简明解释**：`list()` 必须拿到所有元素才能构造列表，于是生成器被从头到尾跑完，数据再次全部进入内存——这是原文点出的最常见误用。
- **例子/自测**：问：把 `read_lines("access.log")` 改成 `list(read_lines("access.log"))` 会怎样？答：生成器被一次性求值，省内存效果完全消失。
- **来源**："基本写法"一节后段
```

### 示例三：素材不足时拒绝出卡

**输入**：`samples/sample-2-short-listicle.md`——5 条一句话建议（全文 81 字符），没有任何理由或数据。

**输出**：不生成 5 张空壳卡片，而是说明原因并给出选项（完整记录见 `samples/sample-2-short-listicle-不成卡说明.md`，以下为节选）：

> 这份素材只有 5 条一句话的建议，没有任何理由、机制或数据支撑。做成卡片的话，"简明解释"这一栏只能靠我补充原文没有的常识，那就变成编造了。
>
> 两个选择：
> 1. 给我同一主题的**带解释的版本**（有原理/原因/数据的正文），我可以出 5~8 张卡；
> 2. 接受"半卡片"——给每条标出"原文未说明理由"，只保留建议本身。这类卡片能提示行动，但没法让人理解为什么，复习价值有限。

### 示例四：学术文献（真实学术论文实测）

**输入**：一篇粘贴进对话的期刊论文《信贷冲击、融资约束与企业风险：基于金融摩擦理论的分析》，正文中的公式已丢失。

**输出**：8 张卡片，序列为：融资约束的两个维度 → 三类主观融资动机 → 基准溢出效应 → 道德风险/投资驱动/税盾效应三类企业对规模与利率两个维度的差异化反应（3 张）→ 可抵押资产的缓冲边界 → 流动资产在两条渠道上的反向作用。

> 说明：该次输出落在本地文件 `信贷冲击融资约束与企业风险-知识卡片.md`，因其派生自已发表期刊论文，为避免版权问题**未随本仓库分发**（已列入 `.gitignore`），此处只引用其中一张卡片作为演示。

其中体现学术特化规则的一张：

```markdown
### 卡片 4：道德风险型企业——两个维度的相反结果

- **核心知识**：对道德风险型企业，信贷利率上升会推高其风险，而信贷规模下降反而会降低其风险。
- **简明解释**：这类企业的借款主要用于分红和转移现金流，而非项目投资，因此收缩信贷规模恰好抑制了它的转移资产行为，变相削弱了道德风险，风险随之下降；利率上升则是直接抬高融资成本。
- **例子/自测**：实证方向与理论一致：利率维度交乘项在 1% 水平显著为正且系数在三组中最高；规模维度交乘项系数为负，但不具有统计显著性。
- **来源**：推论 1、研究假设 1、六（二）
```

注意最后一行：论文里"系数为负但不显著"没有被写成"规模下降降低风险已获证实"。
